# Mi página web (estática)

Página web estática sencilla con HTML, CSS y JavaScript.

Cómo probar localmente:

1. Abrir `index.html` directamente en el navegador.
2. O mejor, sirve la carpeta localmente:
   - Python 3: `python3 -m http.server 8000`
   - Luego abrir `http://localhost:8000`

Qué contiene:
- `index.html` — estructura de la página
- `styles.css` — estilos responsivos
- `script.js` — comportamiento del menú y formulario

Siguientes pasos recomendados:
- Añadir un backend para el formulario
- Convertirla a React/Vite
- Añadir imágenes, branding y SEO
- Desplegarla en Vercel o Netlify
